# Проверки

Пройдены 23 теста, линтер и форматирование. На настоящем PostgreSQL проверены
изоляция строк двух клиентов, запрещённые операции роли и тайм-аут pg_sleep.
Проверены 16 запрещённых форм SQL, а также отклонение вредоносного ответа модели.

Через Docker API выполнены восемь обычных и провокационных вопросов в режиме demo:
ожидаемый статус и результат получены во всех восьми случаях.
Живой Ollama не проверен: локальный сервер недоступен. Эти результаты нельзя
считать оценкой качества LLM или доказательством защиты от всех возможных атак.
